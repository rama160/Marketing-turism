Penggunaan data Google API / Google API data use

Diperbarui / Updated: 26 November 2026. Nusa Penida Experiences mengelola aplikasi internal NPE Studio (NPE SEO Agent). Pemberitahuan ini menjelaskan data Google yang digunakan aplikasi tersebut, terpisah dari Google Analytics opsional bagi pengunjung.

Nusa Penida Experiences operates the internal NPE Studio (NPE SEO Agent) application. This notice describes its Google API data practices separately from optional visitor Google Analytics.

Akses dan jenis data / Access and data categories

Google Search Console API telah aktif. Pemilik mengotorisasi service account untuk mengakses properti website NPE menggunakan izin baca (webmasters.readonly). Aplikasi meminta laporan performa penelusuran web: periode, kueri pencarian, URL halaman, impresi, klik, CTR dan posisi rata-rata, termasuk laporan sementara. Pengunjung wisata tidak diminta memberikan akses ke akun Google, Gmail, Drive, kontak atau data kalender.

The active Google Search Console integration uses an owner-authorized service account with the webmasters.readonly scope for the NPE website property. It retrieves web search reporting periods, search queries, page URLs, impressions, clicks, click-through rates and average positions, including provisional reports. Travel visitors are not asked to authorize access to their Google accounts, Gmail, Drive, contacts or calendars.

Google Ads API / Keyword Planner sedang dalam tahap persetujuan akses, belum terintegrasi dengan agen. Jika akses produksi dan penggunaan yang sesuai disetujui, fitur riset akan meminta ide kata kunci, estimasi pencarian bulanan, riwayat volume, wilayah, bahasa dan persaingan pengiklan dari akun Google Ads yang diotorisasi pemilik. Tidak ada pengambilan data akun Ads produksi oleh agen saat ini. Izin tambahan hanya akan digunakan setelah otorisasi yang diperlukan.

Google Ads API / Keyword Planner is pending access approval and is not yet integrated with the agent. Subject to approved production access and permissible use, keyword research will request keyword ideas, estimated monthly searches, historical volumes, geography, language and advertiser competition from an owner-authorized Google Ads account. The agent does not currently retrieve production Ads account data. Any additional permissions will be used only after the required authorization.

Tujuan penggunaan / Purpose

Data digunakan untuk laporan performa website, pemetaan kata kunci dan halaman, evaluasi visibilitas organik, dan penentuan prioritas informasi perjalanan. Data Ads yang kelak tersedia hanya akan digunakan untuk riset kata kunci sesuai penggunaan yang diizinkan Google. Estimasi volume bukan jumlah booking, dan posisi rata-rata bukan jaminan peringkat Google. Agen riset ini tidak menggunakan data Google API untuk penargetan iklan personal, retargeting, penjualan data atau pembuatan profil pribadi. Tidak ada kampanye atau perubahan pengeluaran iklan melalui fitur riset.

Data supports website performance reports, keyword and page mapping, organic visibility evaluation and travel content priorities. Future Ads data will be used only for keyword research permitted by Google. Estimated demand is not booking volume; average position is not a guaranteed ranking. The research agent does not use Google API data for personalized ad targeting, retargeting, data sales or personal profiling. Its research feature does not create campaigns or change advertising spend.

Penyimpanan, keamanan dan retensi / Storage, security and retention

Permintaan API dijalankan di backend Cloudflare Workers melalui HTTPS; kredensial service account disimpan sebagai secret backend dan tidak dikirim ke browser. Laporan dan rencana keyword disimpan pada Cloudflare D1 dengan akses dashboard yang memerlukan autentikasi pemilik. Kueri yang menyerupai email, URL, nomor panjang atau karakter berisiko ditolak oleh filter; filter tidak menjamin semua kueri bebas data pribadi. Snapshot final dan observasi otomatis yang berusia lebih dari 90 hari dibersihkan saat proses riset berjalan. Cache laporan per periode ditimpa ketika laporan diperbarui; cache yang tidak diperbarui, keyword tersimpan dan catatan turunan pada draf artikel dapat tetap ada sampai dihapus. Data Ads belum disimpan; retensi dan penghapusan akan ditetapkan sebelum integrasi produksi.

API requests run over HTTPS in Cloudflare Workers; service-account credentials are held in backend secrets, not sent to browsers. Reports and keyword plans are stored in Cloudflare D1 behind owner authentication. Filters reject queries resembling emails, URLs, long numbers or unsafe characters, but cannot guarantee that every query contains no personal information. Final snapshots and automatic observations older than 90 days are removed during research runs. Period report caches are replaced on refresh; unrefreshed caches, saved keywords and derived article draft records may remain until deleted. Ads data is not yet stored; its retention and deletion rules will be established before production integration.

Berbagi dan penggunaan terbatas / Sharing and limited use

Data API tidak dijual atau disediakan sebagai kumpulan data publik. Cloudflare menyediakan infrastruktur pemrosesan dan penyimpanan. Untuk penyusunan draf artikel, kata kunci sasaran yang dipilih dapat diproses oleh Cloudflare Workers AI untuk inferensi pembuatan draf; bukan pengiriman kredensial Google atau seluruh laporan pencarian. Draf dan bukti riset hanya dapat ditinjau oleh pemilik yang berwenang; pemilik menyetujui artikel sebelum publikasi. NPE tidak menggunakan data Google API untuk melatih model AI umum. Pengungkapan lain dibatasi pada hal yang diperlukan untuk layanan yang dijelaskan, keamanan, atau kewajiban hukum yang berlaku, sesuai kebijakan Google. Penggunaan dan transfer informasi yang diterima dari Google API akan mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use yang berlaku.

API data is not sold or provided as a public dataset. Cloudflare provides processing and storage infrastructure. To prepare article drafts, a selected target keyword may be processed by Cloudflare Workers AI for draft-generation inference; Google credentials and complete search reports are not submitted to that inference step. Authorized owners review drafts and research evidence and approve articles before publication. NPE does not use Google API data to train general-purpose AI models. Other disclosure is limited to what is necessary for the described service, security or applicable legal obligations, consistent with Google's policies. The use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including applicable Limited Use requirements.
